#  World Data Analysis (SQL + Python)
 
This is a data analysis project where I explored a **world countries dataset** using **SQL and Python**.  
The goal was to analyze population, economy, life expectancy, and languages across countries.

---

##  What this project is about

I connected a **MySQL database** with Python and used SQL queries to fetch data.  
Then I used **Pandas** for cleaning and analysis and **Matplotlib** for visualization.

---

##  Tech Stack

-  Python  
-  MySQL  
-  Pandas  
-  Matplotlib
